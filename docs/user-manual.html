Bienvenido a Vstore

Acerca de este Manual

Este manual le guiará a través de todas las funcionalidades del plugin Vstore para e107 CMS. Aprenderá a configurar su tienda online, gestionar productos, procesar órdenes y mucho más.

Características Principales
  • Múltiples Pasarelas de Pago: PayPal, Mollie (tarjetas, iDEAL, MB WAY, Multibanco, etc.), transferencia bancaria

Instalación

  1. Inicio
  2. Instalación
Requisitos del Sistema
  • e107 CMS v2.3.2 o superior
  • PHP 7.4 o superior
  • Extensión PHP SOAP
  • MySQL 5.6 o superior
  • Composer (para instalar las librerías, entre ellas TCPDF para las facturas PDF)
Paso 1: Descargar el Plugin
  1. Descargue la última versión de Vstore desde el repositorio oficial
  2. Descomprima el archivo ZIP
  3. Suba la carpeta vstore a e107_plugins/
e107_plugins/vstore/
Paso 2: Instalar Dependencias

Vstore utiliza Composer para gestionar dependencias de pasarelas de pago. Ejecute:

cd e107_plugins/vstore/
composer install
Nota: Las dependencias ya están incluidas en el repositorio en la carpeta vendor/
Paso 3: Activar el Plugin
  1. Inicie sesión en el área de administración de e107
  2. Vaya a Admin → Plugins
  3. Localice Vstore en la lista
  4. Haga clic en Instalar
  5. Siga el asistente de instalación
Paso 4: Facturas en PDF

Vstore crea las facturas en PDF con su propia librería (TCPDF), que se instala con Composer. No hace falta ningún plugin adicional:

  1. Ejecute composer install en la carpeta e107_plugins/vstore
  2. Active Crear factura en PDF en Admin → Vstore → Facturas
Importante: Sin la librería TCPDF, las facturas solo estarán disponibles en formato HTML.

Productos Digitales

Para vender productos digitales (ebooks, software, cursos):

  1. Cree el producto normalmente
  2. En Archivos Descargables, suba el archivo desde Media Manager
  3. El archivo se asignará automáticamente al producto
  4. Después de la compra, el cliente podrá descargar el archivo desde su panel
Seguridad

Los archivos descargables están protegidos y solo son accesibles por clientes que han completado la compra.

Presupuestos

  1. Inicio
  2. Presupuestos

Ruta: Admin → Vstore → Productos (precio vacío) y Admin → Vstore → Ventas

Venta o presupuesto

Cada producto puede venderse o pedirse como presupuesto:

  • Con precio: se vende como siempre (carrito, pago y factura).
  • Con el precio vacío (no 0): el producto muestra Precio bajo presupuesto y el botón Presupuesto en lugar de Añadir al carrito. Un precio de 0 es un producto gratuito, no un presupuesto.
Compra y presupuesto pueden ir en el mismo carrito. El carrito muestra dos bloques: Productos para comprar (con precios, cupón y total, botón Finalizar compra) y Productos para presupuesto (sin precios, botón Solicitar presupuesto). Cada botón tramita solo sus líneas; las otras siguen en el carrito para el paso siguiente. Una compra se paga y se factura como siempre y el presupuesto se guarda aparte, sin pago ni número de factura.
Qué ve el cliente

El proceso es el mismo que al comprar, pero sin valores:

  1. Pulsa Presupuesto en los productos que necesita y abre el carrito, que solo lista productos y cantidades.
  2. Pulsa Solicitar presupuesto, indica sus datos y la dirección y revisa el resumen. No hay precios, cupón, envío, impuestos ni método de pago.
  3. Pulsa Enviar solicitud de presupuesto. Recibe un correo con la lista de material pedido y la tienda recibe una copia del mismo mensaje.
Seguimiento en el administrador

Cada solicitud queda guardada en Ventas (filtro Presupuestos; en Estadísticas la tarjeta Presupuestos nuevos cuenta los pendientes y enlaza a ellos) como un registro que no consume números de factura, no modifica el stock y no cuenta como venta en las estadísticas. Estados:

EstadoSignificado
Presupuesto solicitadoSolicitud recibida online
Migrado a la appPasado a la aplicación externa de presupuestos y facturación
Presupuesto aprobadoEl cliente ha aprobado el presupuesto
FacturadoSe ha emitido la factura certificada en la aplicación externa
CanceladoRechazado o anulado (el cliente también puede cancelarlo desde su panel)

Los botones de la ficha del pedido avanzan el estado paso a paso. Vstore no emite facturas de presupuestos: la factura certificada se emite en la aplicación externa. Tras el primer correo, los cambios de estado no envían más correos.

El correo se personaliza en Plantillas de Email → Solicitud de presupuesto.

Categorías

  1. Inicio
  2. Categorías

Ruta: Admin → Vstore → Categorías

Organizar la tienda con categorías

Las categorías organizan los productos y pueden anidarse (categoría padre y subcategorías). Cree al menos una antes de añadir productos.

  1. Vaya a Vstore → Categorías → Crear categoría
  2. Indique el nombre, la descripción y la imagen
  3. Si es una subcategoría, elija la categoría padre
  4. Haga clic en Guardar
Visibilidad: restrinja una categoría a una clase de usuario para ocultarla al resto de visitantes (por ejemplo, una tienda solo para socios).

Variaciones de Productos

  1. Inicio
  2. Variaciones

Ruta: Admin → Vstore → Variaciones

Tallas, colores y otros atributos

Cree un grupo de variaciones una sola vez (por ejemplo Talla con S, M y L) y asígnelo a los productos que lo necesiten. Cada producto admite hasta dos grupos.

  1. Vaya a Vstore → Variaciones → Crear variación y defina el grupo y sus valores
  2. Abra el producto y asigne el grupo en la pestaña de variaciones
  3. Si lo necesita, indique el inventario de cada variación
  • Una variación puede modificar el precio con un importe fijo o un porcentaje.
  • El cliente elige la variación en la página del producto antes de añadirlo al carrito.

Impuestos / IVA

  1. Inicio
  2. Impuestos

Ruta: Admin → Vstore → Preferencias → Tax

Configuración de Impuestos
1. Activar Cálculo de Impuestos

Active la opción "Calculate tax" para habilitar el sistema de impuestos.

2. País del Negocio

Seleccione el país donde está registrada su empresa. Esto es crucial para el cálculo correcto de IVA intracomunitario (UE).

3. Clases de Impuestos

Vstore incluye las siguientes clases de impuestos estándar:

Clase Descripción Uso Típico
None Sin impuestos (0%) Productos exentos de IVA
Standard Tasa estándar Mayoría de productos (ej: 21% en España)
Reduced Tasa reducida Alimentos, libros (ej: 10% en España)
Super Reduced Tasa súper reducida Productos básicos (ej: 4% en España)
4. Validación de VAT ID (Solo UE)

Active "Check VAT id online" para validar automáticamente los números de IVA de empresas contra la base de datos VIES de la UE.

Importante: Ventas B2B Intracomunitarias

Para ventas a empresas de otros países de la UE con VAT ID válido, se aplicará el mecanismo de inversión del sujeto pasivo (reverse charge) y NO se cobrará IVA.

Escenarios de Cálculo de IVA
Escenario IVA Aplicado
Cliente del mismo país (España → España) IVA español (21%)
Cliente UE sin VAT ID (España → Francia) IVA francés (20%)
Cliente UE con VAT ID válido (España → Alemania B2B) 0% (Reverse charge)
Cliente fuera de la UE (España → USA) 0% (Sin IVA)

Pasarelas de Pago

  1. Inicio
  2. Pasarelas de Pago

Ruta: Admin → Vstore → Pasarelas de Pago

Pasarelas disponibles

Cada pasarela tiene su propia pestaña con las credenciales y un interruptor de activación. Active al menos una.

Pasarela Qué necesita
PayPal (estándar y REST) Credenciales de API de su cuenta de PayPal. Use el modo Sandbox para las pruebas.
Mollie Clave de API (de prueba test_... o de producción live_...). Permite elegir los métodos que se ofrecen: tarjeta, PayPal, MB WAY, Multibanco, iDEAL, Bancontact, transferencia, etc.
Transferencia bancaria Los datos de la cuenta que verá el cliente. El pedido queda pendiente hasta que usted lo marque como pagado.
Moneda: los métodos de Mollie que solo aceptan euros (MB WAY, Multibanco, iDEAL, Bancontact, transferencia, domiciliación y tarjeta regalo) no se ofrecen en el checkout si la moneda de la tienda no es EUR. La pestaña de pasarelas indica cuáles se ocultan.
Mollie y los pagos pendientes: con métodos como MB WAY o Multibanco el cliente puede tardar en pagar. Vstore crea el pedido al momento y Mollie avisa del pago (webhook), de modo que el pedido se actualiza aunque el cliente no vuelva a la tienda. En un pedido de Mollie aún nuevo puede usar el botón Comprobar el pago en Mollie.

Pruebe siempre cada pasarela en modo de pruebas antes de pasar a producción.

Envíos

  1. Inicio
  2. Envíos

Ruta: Admin → Vstore → Preferencias → Envíos

Costes de envío

Active los envíos en la pestaña Envíos de las Preferencias y elija cómo se calcula el coste:

  • Suma de todos los artículos: suma el coste de envío de cada artículo del carrito.
  • Suma de artículos únicos: suma el coste de cada producto distinto una sola vez.
  • Escalonado: el coste depende de umbrales del precio o del peso del pedido. Empiece por el umbral más bajo y haga que el último supere su pedido más grande.

El coste de envío propio de cada producto se indica en la ficha del producto.

Cada cambio de estado envía al cliente el correo correspondiente (ver Plantillas de Email).

Reembolsos y factura
  • Reembolso: con las pasarelas que lo permiten (Mollie, PayPal) el pago se devuelve desde el propio pedido. Con transferencia bancaria el pedido se marca como reembolsado, pero la devolución del dinero la hace usted.
  • Factura: el icono de la factura abre o genera el PDF del pedido (ver Facturas).

Clientes

  1. Inicio
  2. Clientes

Ruta: Admin → Vstore → Clientes

Datos de los clientes

Vstore guarda los datos del último pedido de cada cliente registrado para rellenar el formulario del checkout. Desde esta pestaña puede consultarlos y corregirlos:

  • Facturación: nombre, empresa, NIF/IVA, código fiscal, dirección, correo y teléfono.
  • Envío: la última dirección de envío y si se usa.
  • Campos adicionales: los que defina en las Preferencias del checkout.
  • Notas: anotaciones internas que el cliente no ve.

El cliente también puede editar sus datos y ver sus pedidos desde su panel en la tienda.

Facturas

  1. Inicio
  2. Facturas

Ruta: Admin → Vstore → Configuración de Facturas

Facturas en PDF
  1. Compruebe que ejecutó composer install en la carpeta del plugin (instala la librería TCPDF)
  2. Active Crear factura en PDF
  3. Defina el prefijo de numeración, el siguiente número, el plazo de pago y el formato de fecha
  4. Escriba el texto de despedida y los cuatro bloques del pie (contacto, datos fiscales, datos bancarios...)
  5. Revise el resultado en la pestaña Vista previa

La factura se adjunta al correo del cliente y está disponible en su panel. Desde el administrador, el icono de factura del pedido la abre o la regenera.

Si la factura no se adjunta: revise que la creación de PDF esté activada y que exista vendor/tecnickcom/tcpdf.

Solución de Problemas

  1. Inicio
  2. Solución de Problemas
Activar Modo Debug

Para depurar problemas, active el modo debug de Vstore:

  1. Edite el archivo e107_config.php
  2. Agregue la siguiente línea: 
    define('e_DEBUG_VSTORE', true);
  3. Los logs se mostrarán en el footer de cada página
Importante: Desactive el modo debug en producción por razones de seguridad y rendimiento.
Problemas Comunes
El cupón no se aplica
  • Verifique que el cupón esté activo
  • Compruebe las fechas de inicio/fin
  • Revise que los productos estén en categorías permitidas
  • Verifique que no se haya excedido el límite de uso
El IVA no se calcula correctamente
  • Verifique que "Calculate tax" esté activado
  • Confirme que el "Business country" sea correcto
  • Revise las clases de impuestos asignadas a los productos
  • Para clientes UE, verifique que el país se detecta correctamente
Error al procesar pago
  • Verifique las credenciales API de la pasarela
  • Asegúrese de usar credenciales de producción (no sandbox)
  • Revise los logs de la pasarela de pago
  • Compruebe que el plugin vendor/ esté completo
